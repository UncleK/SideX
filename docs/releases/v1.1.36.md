# SideX v1.1.36 candidate

2026-11-08 — local candidate; not submitted to Chrome Web Store.

## English

- Supports X's new x-web structure so main-post text/padding opens replies in place.
- Restores short replies, Unicode/escaped text, attachments, counts, flags and reply relationships.
- Adapts native reply/quote routing, textarea tools, profile cards, More/Share/Grok entry points and photo docking, retaining older-client support.
- Modern mutations use X's Relay network; missing confirmation does not trigger an alternate send or automatic retry.

263 tests pass. Isolated browser checks covered real reading, target-user menus/cards, native Reply/GIF/Escape, and an intercepted CreateTweet with local confirmation. No test posts/account mutations were made. The actual candidate extension/fresh ZIP has not been loaded. Photo visual acceptance, real sends/uploads/actions, translation and Grok analysis remain unverified. See [compatibility evidence](../X_WEB_COMPATIBILITY.md).
