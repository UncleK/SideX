# SideX v1.1.39

## English

- Updates inline reply requests for X's current web client to address HTTP 422 errors.
- Preserves X's native hover background on the selected post while the sidebar is open. The background follows the selected post and clears when the sidebar closes.

All 274 regression tests passed. In Chrome, the background matched X's hover color and cleared on switching posts and closing the sidebar. A live plain-text reply sent through SideX returned HTTP 200 and appeared in X's own thread view. Long and image replies were covered by automated tests. See the [QA record](../QA_20261108.md).

Use the attached `SideX-v1.1.39.zip` for the Chrome Web Store update. The [combined listing text](../STORE_LISTING.md) is ready to paste.
