# SideX v1.1.38

2026-11-08

## English

- Supports X's new x-web client. Clicking a main post's text or blank area opens SideX beside the timeline again. Explicit links, quoted posts and media retain their native behavior.
- Restores reply bodies, Unicode/escaped text, media, counts and reply relationships in X's new response format.
- Adapts native reply/quote, profile-card and menu entry points. Fixes transparent profile cards, missing focal/pinned post markers and delayed Show more expansion.
- Keeps photo comments docked when X unmounts hidden native posts; collapse and restore continue to use X's viewer.
- Fixes Chinese and English emoji category labels displaying internal translation keys.

### Validation

All 273 automated regression tests pass. Four actually loaded page scripts were matched byte-for-byte to the 1.1.37 package and core reading, profile cards, pinning, menus and photo collapse/restore passed installed-code checks. The subsequent 1.1.38 Chinese emoji labels were also checked in Chrome; English labels have automated coverage. UI send requests were intercepted before transmission and answered with local failure/success responses to check draft retention and recipient reset. No test replies were published.

Following a reported `Failed to fetch` warning, the current main, child and pagination requests returned HTTP 200; the user confirmed replies still loaded normally. A new regression checks that a failed subreply read preserves existing content and the draft, does not retry in a loop, and recovers on manual retry. The original network failure could not be reconstructed, and its diagnostic logging was retained.

Real publication/uploads/account mutations, translation/Grok results, a real old-client environment and fresh ZIP installation remain outside this verification. See the [QA matrix](../QA_20261108.md). The ZIP contains only the 18 allow-listed files and matches the packaged working-tree files byte-for-byte.

### Store update

Upload `SideX-v1.1.38.zip` to the existing Chrome Web Store item. Paste `SideX-v1.1.38-store-description.txt` into the listing: English first, then Chinese. A short update summary, upload guide, checksums and verification record are attached to the GitHub release. GitHub-generated Source code archives are not store upload packages. Store upload and review submission remain a maintainer step.

Refresh X after updating. Send or copy unfinished text first; refreshing clears temporary drafts.

## 中文

- 适配 X 新版 x-web，恢复点击主帖正文、空白处原位打开 SideX。链接、引用帖和媒体继续使用原生交互。
- 恢复新版响应中的评论正文、Unicode/转义文字、媒体、计数和回复关系。
- 适配原生回复/引用、资料卡和菜单入口；修复资料卡透明透字、主帖阅读/固定高亮缺失，以及延迟挂载后的“显示更多”展开。
- 修复图片侧栏因隐藏原生帖子被卸载而反复切换，保留 X 图片查看器的收起与恢复。
- 修复中英文表情分类显示内部翻译键名的问题。

### 验证

全部 273 项自动化回归通过。四份实际加载的页面脚本已与 1.1.37 包逐字比对，核心阅读、资料卡、固定、菜单和图片收放完成实装检查。后续 1.1.38 中文表情分类也已在 Chrome 核对，英文分类有自动化覆盖。发送请求在出站前拦截，通过本地失败/成功回执验证草稿保留及回复对象复位，未发布测试回复。

针对用户提供的 `Failed to fetch` 记录，当前主帖、下级回复和分页请求复测均返回 HTTP 200，用户确认右侧仍能正常加载。新增回归验证下级回复读取失败后保留内容与草稿、不自动循环重试，并能手动重试恢复。无法还原原先网络失败的具体原因，诊断日志继续保留。

真实发送/上传/账号写入、翻译/Grok 结果、旧版前端实机环境和新 ZIP 安装仍未验收，详见 [QA 矩阵](../QA_20261108.md)。ZIP 仅含允许列表中的 18 个文件，逐项与打包工作区文件进行字节校验。
