# SideX v1.1.40

## English

- Restores in-place opening from a post's text or blank area after a change to X's web layout.
- Keeps the sidebar at the current scroll position when loading more replies in a comment thread.

All 280 automated tests passed. The maintainer checked the updated local build in Chrome and approved release. See the [QA record](../QA_20261108.md).

Use the attached `SideX-v1.1.40.zip` for the Chrome Web Store update. The [bilingual store description](../STORE_LISTING.md) is ready to paste.
