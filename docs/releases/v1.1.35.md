# SideX v1.1.35

2026-11-04

## English

- After a successful reply, the composer clears the submitted draft and selected recipient. Your next reply defaults to the main post. A separate unfinished draft for the main post is retained.
- Failed sends keep their text and recipient. A late success confirmation cannot clear a newer draft or change a different reply target. Quick replies and transferred official replies follow the same rule.
- Hover @mentions in reply text or reply-to links to open X's native profile card. Users absent from the main page use X's own loaded profile component, preserving native interactions such as mutual followers and Profile Summary when available. A readable fallback remains available if X's native component cannot load.

### Validation

All 230 regression tests pass. The user reloaded the actual local extension, and Chrome checks on X confirmed native cards for a user absent from the timeline and reply-recipient reset. Send requests were intercepted before reaching X and answered with local synthetic confirmations; no test replies were published. The packaged JavaScript matches that verified candidate. The ZIP is checked against the 18-file package allowlist; a fresh ZIP installation was not tested.

### Store update

Upload `SideX-v1.1.35.zip` to the existing Chrome Web Store item, then paste `SideX-v1.1.35-store-description.txt` into the listing. It contains English first, then Chinese. A short update summary and upload guide are also attached. GitHub's generated Source code archives are not store packages. Chrome Web Store upload and review submission are a separate maintainer step.

Refresh X after updating. Send or copy unfinished text first, since refreshing clears temporary drafts.

## 中文

- 回复成功后清空已发送的草稿和当前回复对象，下一条默认回复主帖。主帖如有其他未完成草稿，会继续保留。
- 发送失败保留文字与对象；旧回复的迟到成功回执不会覆盖新草稿或更换新回复对象。快捷回复与转交官方回复框的草稿使用相同规则。
- 回复正文中的 @用户和“回复 @用户”链接支持 X 原生资料卡。主页面没有对应用户时，使用 X 已加载的原生组件，保留共同关注、Profile Summary 等账号可用交互；原生组件无法加载时保留可读的后备卡片。

### 验证

全部 230 项回归测试通过。用户重新加载实际本地扩展后，已在 Chrome 的 X 页面检查主信息流中没有的用户资料卡，以及发送后的回复对象复位。发送请求在到达 X 前拦截，使用本地合成成功回执，未发布测试回复。打包的 JavaScript 与该验证候选一致。ZIP 按 18 项允许列表逐项校验，未进行新 ZIP 安装测试。
