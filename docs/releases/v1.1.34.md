# SideX v1.1.34

2026-10-28

## 中文

### 回复加载

- 默认二级回复数量可选 1、2、3、5；可见分支会按需继续读取分页，补齐所选数量。
- 首次点击“加载更多回复”追加默认数量加 2 条。例如默认 3 条时，再显示 5 条，共 8 条；默认 1 条时，再显示 3 条，共 4 条。
- 第二次点击“展开并加载全部回复”，连续加载所选分支的普通回复。按钮不再显示括号内的追加数量。
- 收起或修改默认数量后恢复默认预览，保留当前草稿和阅读位置。作者连续自回复保持完整；屏幕外分支不预取，折叠回复仍需单独展开。错误、空页或重复游标会停止连续加载。

### 设置

- 常用选项集中在“评论阅读”，回复方式、图片、翻译与侧栏选项放在可折叠的“更多设置”。自动加载和固定侧栏的作用说明更清楚。
- “完整显示回复长文”默认开启；此前明确保存的关闭状态仍会保留。
- 图片评论区先显示“SideX 样式”，再显示“官方样式”。
- “全部恢复”重置全部选项、侧栏宽度和语言偏好，保留当前回复草稿。抽屉前端的宽度重置操作继续可用。
- 只有修改设置后才显示橙色“请刷新 X 生效”。更新扩展或修改设置后，请刷新 X；刷新前先发送或复制草稿，页面刷新会清空临时草稿。

本版也包含 v1.1.33 对 X 原生文章引用大段空白的布局修复。

## English

### Reply loading

- Choose an initial sub-reply preview of 1, 2, 3 or 5. Visible branches follow enough pages to fill the selected preview when replies are available.
- The first click on Load more replies adds the selected default plus 2. A default of 3 adds 5 for 8 total; a default of 1 adds 3 for 4 total.
- The second click on Expand and load all replies follows the selected branch's ordinary replies. Buttons no longer show the parenthesized extra count.
- Collapsing or changing the default resets the preview while preserving the current draft and reading position. Author continuations stay visible. Offscreen branches are not prefetched, folded replies require a separate reveal, and errors, empty pages or repeated cursors stop continuous loading.

### Settings

- Common options appear under Reading comments. Reply tools, photo comments, translation and sidebar options are grouped under collapsible More settings, with clearer descriptions of automatic loading and pinning.
- Show full reply text defaults to on. An explicitly saved off preference is preserved.
- Photo comments lists SideX before Official.
- Reset all restores every option, sidebar width and the browser-language default while preserving the current reply draft. The drawer's width reset remains available.
- A short orange Refresh X to apply reminder appears only after a preference changes. Refresh X after updating SideX or changing settings. Send or copy unfinished text first, since refreshing clears temporary drafts.

This version also includes v1.1.33's layout fix for long blank areas in native X Article quotes.
