Privacy Policy for SideX

Last updated: October 9, 2026

Thank you for choosing SideX ("the Extension"). We respect your privacy and are committed to protecting it. This Privacy Policy explains our practices regarding user data and permissions.

1. Browser Processing and Network Requests

SideX is an entirely client-side productivity extension:

  • Data Used for Features: SideX processes X posts and profiles you open, relationship information in profile cards, and text/media you submit as replies. It uses your current X session for authenticated requests. It does not build a browsing-history log, run analytics, or read your password.
  • No SideX Servers: SideX does not operate remote servers, analytics, or telemetry services. Requests go directly to X, media hosts, and, when selected, Google Translation. These services receive network information required to serve a request.

2. Permissions and Their Use

SideX requests only the minimum permissions necessary for its functionality:

  • storage: Saves UI and translation preferences using chrome.storage.sync, with local storage as a fallback. Your browser account may sync these preferences. Drawer width stays local; post text and translation results are not written to synced storage.
  • host_permissions: Content scripts run on x.com and twitter.com. Upload hosts support reply attachments; translate.googleapis.com supports optional Google translation requests from the extension worker.

3. Account Security & Session

SideX operates directly within your active browser session:

  • It reads active X request headers and the CSRF cookie to make authenticated X requests. These values stay in page memory and are not sent to Google or a SideX server. SideX does not read your password.
  • All interactions (e.g. liking, replying, loading threads) are performed directly through your own authenticated session with X.

4. Third-Party Services

SideX contains no third-party tracking scripts, ads, or analytics services.

X official translation is the default. If you select Google and click Translate, post text and the target language are sent directly to translate.googleapis.com, without X authentication headers or cookies. Results are cached temporarily in memory.

The existing-extension option leaves readable text in the page and hides SideX translation buttons. Other translators follow their own settings and privacy policies; SideX does not automatically invoke arbitrary extensions.

Displaying X media and bundled GIF choices requests assets from their hosts, including X media hosts and GIPHY. Reply attachments selected by you are uploaded to X.

5. Open Source & Transparency

SideX is fully open source. You can inspect the source code at any time on GitHub: https://github.com/UncleK/SideX.

6. Contact

If you have any questions or feedback, please open an issue at: GitHub Issues.
